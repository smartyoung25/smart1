## 우선순위 (ROI)
1. **ERA5/AgERA5** → M1 토마토 재학습(무료·즉시) — 모델 백로그 직접 해결
2. **농업기상재해 조기경보(agmet.kr)** → DecisionDeck 재해카드(가치 정합 최고)
3. **농축산물 소득정보(AMIS)** → C14 경영성과 실데이터(Mock 대체)
4. **Sentinel-2 NDVI** → F5·F2 Mock 제거
5. **AIHub 질병이미지** → G5·C4 자체 병해모델
