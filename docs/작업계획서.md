## 2. 해결해야 할 문제 목록

### 2-1. 즉시 조치 (환경 설정 — 코드 변경 없음)

#### [P0-A] `.env` 파일 생성 및 키 설정
- **원인**: `KMA_SERVICE_KEY` 등 모든 환경변수가 `.env` 파일 없이는 로드되지 않음
- **영향**: KMA 날씨 API 전체 비활성화, DB 연결 불가, Airflow 크래시
- **조치**:
  ```bash
  cp .env.example .env
  # .env 편집:
  # KMA_SERVICE_KEY=<공공데이터포털 키>
  # POSTGRES_PASSWORD=<강한 비밀번호>
  # AIRFLOW_ADMIN_PASSWORD=<강한 비밀번호>
  # AIRFLOW_FERNET_KEY=$(python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())")
  ```

#### [P0-B] `load_dotenv()` 추가
- **원인**: Docker 없이 직접 실행 시 `.env`가 자동 로드되지 않음
- **파일**: `api/main.py` 상단
- **조치**:
  ```python
  from dotenv import load_dotenv
  load_dotenv()
  ```

### 2-2. 단기 작업 (1~2주)

#### [P1-A] TimescaleDB 연결 + 수동 입력 영속화
- **원인**: `_MANUAL_ENV`, `_MANUAL_COSTS` 가 in-memory → 재시작 시 초기화
- **파일**: `api/routers/farmer.py:293~297`, `docker-compose.yml`
- **조치**: `docker-compose up db` 기동 → SQLAlchemy로 `manual_inputs` 테이블 read/write 교체
- **선행 조건**: [P0-A] 완료

#### [P1-B] 기초자료 환경 CSV 적재 (`extract_rda_stats.py` 확장)
- **원인**: `기초자료/환경_YYYY.csv` (58~81MB × 5개) 미활용 상태
- **효과**: 환경-수확량 민감도 계수 실데이터 보정 가능
- **조치**: `pipelines/initial_load.py` 실행 → TimescaleDB `env_measurements` 테이블 적재
- **선행 조건**: [P1-A] 완료, Q1 결정 필요 (→ `phase1-work-report.md` §7-2)

#### [P1-C] 이암허브 2025년 CSV 적재
- **파일 위치**: `기초자료/.../스마트팜(이암허브)/환경_2025.csv`, `생육_딸기_2025.csv`
- **주의**: 현재 23행 — 데이터 양이 매우 적어 통계적 보정 효과 제한적
- **조치**: TimescaleDB 적재 후 GDD 파라미터 보정 여부 검토

#### [P1-D] 코드 신뢰도 항목 수정 (즉시 가능)
- **파일**: `api/routers/farmer.py`

| 항목 | 현재 값 | 수정 내용 |

| farm_001 `kamis_price` | 12,000원 (허브 단가) | 오이 단가 1,845원으로 수정 |
| farm_001 `yield_kg_m2` | 0.82 | 오이 실수율 18.25로 수정 |

### 2-3. 중기 작업 (1~2개월)

#### [P2-A] KAMIS 실시간 가격 복구
- **현재 상태**: API 인증 실패, `kamis_adapter.py` 는 변환만 담당
- **조치 방안 A**: KAMIS 공공API 키 재발급 후 HTTP 클라이언트 wrapper 구현
- **조치 방안 B**: 주 1회 웹 크롤링 → `price_stats.json` 갱신 Airflow DAG 추가

#### [P2-B] 생육 통계 추출 스크립트 신규 작성 (`extract_growth_stats.py`)
- **출처**: `기초자료/생육_작목_YYYY.csv` × 5년 × 5 작목
- **출력**: `api/data/growth_stats.json` — 작목별 초장·엽수·착과수 주차별 분포

#### [P2-C] M2 수확량 예측 모델 학습
- **현재**: `profit_optimizer.yield_predict_fn` = 온도 단순 선형 스텁
- **목표**: RandomForest 또는 LightGBM, 입력 15개 변수, MAPE ≤ 25%
- **선행 조건**: [P1-B], [P2-B] 완료

#### [P2-D] JWT 인증 미들웨어 구현
- **현재**: 인증 없음 — 전체 API 공개
- **조치**: FastAPI `Depends` + JWT Bearer 토큰 기반 인증 추가
