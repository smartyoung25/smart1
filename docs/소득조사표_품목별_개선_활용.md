## 1. 딸기 (류창영) — 시설 완비·노동집약

**이전(조사표)**: 상각비 대농구 675,000 + 영농시설 783,000(템플릿). 딸기 특성(저온관리·수작업 수확)·시설 완비 미반영.
**이후**: 측창·천정/측면 보온·차광·관수 **전 시설 ○ → CAPEX 최다(계수 1.00, 감가 1,458,000)**. 자산별 분해(온실구조·이중보온·차광·자동관수)로 저온기 보온 투자와 감가가 명시됨.
**품목별 활용방안**:
- 노동집약 작목 → **관리 자동화(유인·적엽 보조)** 투자 ROI 분석에 실 감가+노무절감 대조.
- 측면보온까지 완비 → 난방비 절감 실적을 감가상각 대비로 검증(투자 회수기간).

## 2. 방울토마토 (박경종) — 다수확·측면보온 미설치

**이전(조사표)**: 딸기와 동일 템플릿 값 → 방울토마토의 다수확(65,464kg)·측면보온 부재가 비용에 안 잡힘.
**이후**: **측면 보온스크린만 ✕**(나머지 ○) → 계수 0.92, 감가 1,341,360. 보온 투자 여지가 자산등록부에 공백으로 드러남.
**품목별 활용방안**:
- **측면보온 신규 투자 시뮬레이션** — 추가 CAPEX(감가 증분) vs 난방비 절감 편익. 미설치가 명시되어 투자 우선순위 근거.
- 다수확 → 수확 인건비·포장재비 비중 큼(수확량 연동 비용). 자동 선별·포장 투자 검토.

## 3. 완숙토마토 (김선환) — 최다 생산량·환기/관수 수동

**이전(조사표)**: 동일 템플릿 → 최다 생산량(198,797kg)과 **측창·관수관비 부재**(수동 운영)가 비용구조에 미반영.
**이후**: **측창(환기)·관수관비장치 ✕** → 계수 0.82, 감가 1,195,560. 자동화 설비 공백이 가장 큼 → 노무 의존 구조가 드러남.
**품목별 활용방안**:
- **환기·관수 자동화 투자 여지 최대** — 최다 생산량이라 규모 효과 큼. 자동화 CAPEX(감가+전기 OPEX) vs 노무·수율 편익 ROI가 핵심.
- 등유+제습기 난방 → 수도광열(경유) 비중·습도관리 비용을 난방기 감가와 연동 분석.

## 4. 참외 (강석구) — 반촉성·저투자·관수 고장

**이전(조사표)**: 동일 템플릿(1,458,000) → **반촉성·최소 시설**인 참외가 딸기와 같은 투자비로 잡혀 소득 왜곡.
**이후**: 보온·차광 **없음**, 측창만 ○, **관수관비 고장** → 계수 0.70, 감가 **1,020,600(최소)**. 저CAPEX 특성이 정직하게 반영.
**품목별 활용방안**:
- **관수관비 '고장' → 재투자 vs 수리 의사결정** 최우선. 교체(CAPEX) 시 감가 증분, 수리(OPEX) 시 수리유지비 — 등록부가 갈림길 제시.
- 반촉성·심야전기 → 난방비 최소. **저투자·저비용 구조**로 소득률 방어. 신규 진입농가에 저CAPEX 표준 모델로 활용.

## 5. 종합 — 품목별 개선의 의미

| 관점 | 이전 | 이후 |
|------|------|------|
| 품목 구분 | 4작목 CAPEX 동일(템플릿) | **시설 실구성으로 차등** (참외 −30% vs 딸기) |
| 투자 공백 | 안 보임 | 방울=측면보온·완숙=환기/관수·참외=보온/차광 **공백이 등록부에 노출** |
| 재투자 신호 | 없음 | 참외 관수 '고장' 등 **교체 시점 포착** |
| 소득 정확도 | 상각비 수기·품목 무차별 | 감가상각을 ERP·비용모델에 **품목·면적 차등 자동 반영** |

## 6. 활용 로드맵 (품목 공통)
1. **견적 입력 → 품목별 실 감가상각** — 각 농가 견적서로 register 채우면 위 계수 대신 실 취득가 기반 계산.
2. **품목별 투자 ROI 카드** — 완숙(환기·관수)·방울(측면보온)·참외(관수교체)처럼 **품목별 최우선 투자**를 자동 제안.
3. **작목 전환·신규 진입 가이드** — 저CAPEX(참외) vs 고CAPEX·고수확(완숙) 투자 프로파일 비교.
4. **과업① 연계** — 20개소 견적 축적 시 품목·규모·지역별 표준 CAPEX/감가 벤치마크 확립.
