> ★ 공통 현안: 조사표 `소득분석2` 상각비(675,000/783,000)·이름'홍길동'은 4작목 **동일한 샘플 템플릿** → 품목 구분이 없었다.

## 1. 딸기 — 시설 완비·노동집약 (표본 류창영)

**이전(조사표)**: 상각비 대농구 675,000 + 영농시설 783,000(템플릿). 딸기 특성(저온관리·수작업 수확)·시설 완비 미반영.
**이후**: 5농가 실측 계수 **0.934**(감가 1,361,772). 완비도 편차가 작아(0.91~0.97) **시설이 표준화된 작목**. 자산별 분해(온실구조·이중보온·차광·자동관수)로 저온기 보온 투자와 감가가 명시됨.
**품목별 활용방안**:
- 노동집약 작목 → **관리 자동화(유인·적엽 보조)** 투자 ROI 분석에 실 감가+노무절감 대조.
- 보온 완비 → 난방비 절감 실적을 감가상각 대비로 검증(투자 회수기간).

## 2. 방울토마토 — 다수확·측면보온 공백 (표본 박경종)

**이전(조사표)**: 딸기와 동일 템플릿 값 → 방울토마토의 다수확(평균 78,344kg)·측면보온 부재가 비용에 안 잡힘.
**이후**: 5농가 실측 계수 **0.910**(감가 1,326,780). 표본농가는 측면 보온스크린만 ✕(나머지 ○). **완비도 편차 최대(0.76~0.97)** — 농가별 시설 격차가 가장 크다.
**품목별 활용방안**:
- **측면보온 신규 투자 시뮬레이션** — 추가 CAPEX(감가 증분) vs 난방비 절감 편익. 미설치 농가에 투자 우선순위 근거.
- 다수확 → 수확 인건비·포장재비 비중 큼(수확량 연동 비용). 자동 선별·포장 투자 검토.

## 3. 완숙토마토 — 최다 생산량·대부분 완비 (표본 김선환) ★정정

**이전(조사표)**: 동일 템플릿 → 최다 생산량(평균 164,314kg, 최대 450k)이 비용구조에 미반영.
**이후**: 5농가 실측 계수 **0.940**(감가 1,370,520) — **4작목 중 최고**. ★ 표본농가(김선환)는 측창·관수관비가 ✕였으나, **5농가 평균은 대부분 완비**다. 초기 단일샘플로 "자동화 공백 최대"라 판단했던 것을 실측이 정정했다 — 자동화 공백은 완숙 전반이 아니라 **농가 편차(0.76~1.00)**다.
**품목별 활용방안**:
- 최다 생산량이라 규모 효과 큼. **시설 미비 개별 농가에 한해** 환기·관수 자동화 CAPEX(감가+전기 OPEX) vs 노무·수율 ROI 제안(전작목 일괄 아님).
- 등유+제습기 난방 → 수도광열(경유) 비중·습도관리 비용을 난방기 감가와 연동 분석.

## 4. 참외 — 반촉성·저투자·관수 고장 (표본 강석구)

**이전(조사표)**: 동일 템플릿(1,458,000) → **반촉성·최소 시설**인 참외가 딸기와 같은 투자비로 잡혀 소득 왜곡.
**이후**: 5농가 실측 계수 **0.712**(감가 **1,038,096·최소**). 범위 0.67~0.75로 일관되게 낮아, **4작목 중 유일하게 확연히 낮은 저CAPEX 특성**이 실측으로 확인됨. 표본농가는 보온·차광 없음·측창만 ○·관수관비 고장.
**품목별 활용방안**:
- **관수관비 '고장' → 재투자 vs 수리 의사결정** 최우선. 교체(CAPEX) 시 감가 증분, 수리(OPEX) 시 수리유지비 — 등록부가 갈림길 제시.
- 반촉성·심야전기 → 난방비 최소. **저투자·저비용 구조**로 소득률 방어. 신규 진입농가에 저CAPEX 표준 모델로 활용.

## 5. 종합 — 품목별 개선의 의미

| 관점 | 이전 | 이후(실측) |
|------|------|------|
| 품목 구분 | 4작목 CAPEX 동일(템플릿) | **시설 실구성으로 차등** — 참외만 약 −24%, 나머지 3작목은 0.91~0.94로 유사 |
| 투자 공백 | 안 보임 | 농가별 시설 격차(방울·완숙 완비도 0.76~) **등록부에 노출** |
| 재투자 신호 | 없음 | 참외 관수 '고장' 등 **교체 시점 포착** |
| 소득 정확도 | 상각비 수기·품목 무차별 | 감가상각을 ERP·비용모델에 **품목·면적 차등 자동 반영** |

## 6. 활용 로드맵 (품목 공통)
1. **견적 입력 → 품목별 실 감가상각** — 각 농가 견적서로 register 채우면 위 계수 대신 실 취득가 기반 계산.
2. **품목별 투자 ROI 카드** — 참외(관수교체)·방울(측면보온)·시설 미비 완숙 농가(환기·관수)처럼 **농가별 최우선 투자**를 자동 제안.
3. **작목 전환·신규 진입 가이드** — 저CAPEX(참외) vs 고CAPEX·고수확(완숙) 투자 프로파일 비교.
4. **과업① 연계** — 20개소 견적 축적 시 품목·규모·지역별 표준 CAPEX/감가 벤치마크 확립.

> 현재 계수·생산량만 실측이고 감가상각 **금액**은 표준 템플릿 기반 — 과업①에서 견적서·시방서를 조사항목에 포함하면 개선안이 실데이터로 즉시 작동한다.
