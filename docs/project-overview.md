# 스마트팜 수익성 향상 플랫폼 — 프로젝트 개요

> 딸기·토마토·방울토마토·참외 4개 작목 | 5개 농가 기반 → 50개+ 농가 확장 | Phase 1~4 단계별 실행

---

## 1. 프로젝트 개요

### 목적
스마트팜 농가의 **환경 데이터·생육 데이터·시장 단가**를 통합 분석하여 수확 예측, 병해 진단, 매출 추정을 자동화하는 AI 기반 수익성 향상 플랫폼 구축

### 대상 작목
| 작목 | 비고 |
|------|------|
| 딸기 | DSSAT CROPGRO-Strawberry 물리모델 적용 |
| 토마토 | TOMGRO 물리모델 + LSTM 시계열 |
| 방울토마토 | WUR AGC 공개 데이터 전이학습 |
| 참외 | GDD 기반 수확시기 예측 |

### 초기 규모
- **5개 농가** 기반 데이터 수집·모델 학습 → Phase 2부터 10~15개, Phase 4에서 50개+로 확장
- 데이터 소스: 현장 IoT 센서, 농진청 API, KAMIS 단가 API, AI Hub 병해 데이터, WUR 공개 데이터셋

### 핵심 AI 모듈 (7개)
| 모듈 | 기능 | 우선순위 |
|------|------|---------|
| M1 | 환경 → 생육 예측 | 1순위 (핵심) |
| M2 | 생산량 예측 | 1순위 |
| M3 | 수확시기 예측 | 1순위 |
| M4 | 매출 추정 | 2순위 |
| M5 | 병해 진단 | 1순위 (즉시) |
| M6 | 에너지 효율 | 3순위 |
| M7 | 품질 예측 | 4순위 (실측 필수) |

## 2. Phase별 실행 일정

```
Phase 1 │████████████░░░░░░░░░░░░░░░░░░░░░░░░░░│  0 ~ 3개월   기반 구축 + 베타 출시
Phase 2 │░░░░░░░░████████████░░░░░░░░░░░░░░░░░░│  3 ~ 6개월   정밀화 + 매출 추정
Phase 3 │░░░░░░░░░░░░░░░░████████████████░░░░░░│  6 ~ 12개월  실측 보강 + 품질 모듈
Phase 4 │░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░██████│  12개월+     확장 + 자동화
```

### Phase 1 — 기반 구축 + 베타 출시 (0~3개월)
- 5농가 데이터 표준 스키마 DB 구축 및 정제
- 농진청·KAMIS·AI Hub 외부 데이터 연동
- M1(생육 예측)·M3(수확시기)·M5(병해 진단) 우선 개발
- API Gateway + 농가 대시보드 베타 출시
- **인프라:** GPU 서버, TimescaleDB, Docker Compose 환경

### Phase 2 — 정밀화 + 매출 추정 (3~6개월)
- M4 매출 추정 모듈 출시 (KAMIS 단가 × 생산량 3-way 시나리오)
- M6 에너지 효율 (EnergyPlus 시뮬레이션)
- Airflow 자동 재학습 파이프라인 구동
- Prometheus + Grafana 운영 모니터링
- 모바일 앱 베타 출시 (iOS/Android)
- 연계 농가 10개 이상으로 확장

### Phase 3 — 실측 보강 + 품질 모듈 (6~12개월)
- 5농가 굴절당도계·스마트전력계 설치 → 실측 데이터 3작기 이상 축적
- M7 품질 예측 모듈 출시 (당도·등급 분류)
- 에너지 실측 ML 보정 (±8%)
- WUR 연구진 데이터 공유 MOU 체결 (목표)
- 연계 농가 20개 이상

### Phase 4 — 확장 + 자동화 (12개월+)
- Kubernetes 기반 오케스트레이션 전환
- 연합학습(Federated Learning) 파일럿 — 농가 원시 데이터 비공유
- WUR Autonomous Greenhouse Challenge 2026 참가
- PhysicsNeMo 에너지 서로게이트 모델 구축
- 연계 농가 50개+

## 3. Phase별 KPI 목표치

| 지표 | Phase 1 | Phase 2 | Phase 3 | Phase 4 |
|------|---------|---------|---------|---------|
| 환경→생육 R² | ≥ 0.62 | ≥ 0.75 | ≥ 0.85 | ≥ 0.90 |
| 생산량 MAPE | ≤ 25% | ≤ 18% | ≤ 12% | ≤ 8% |
| 수확시기 예측 오차 | ± 5일 | ± 3일 | ± 2일 | ± 1일 |
| 병해 진단 정확도 | ≥ 92% | ≥ 93% | ≥ 95% | ≥ 96% |
| 매출 추정 오차 | ± 30% | ± 22% | ± 15% | ± 10% |
| 에너지 예측 오차 | 시뮬 ± 20% | ± 15% | ± 8% | ± 5% |
| 품질 예측 F1 | 문헌 처방만 | ≥ 0.60 | ≥ 0.75 | ≥ 0.85 |
| 연계 농가 수 | 5개 | 10~15개 | 20~30개 | 50개+ |

## 5. 확장 로드맵

### 농가 확장 계획 (Phase 2~3)
- 온보딩 프로세스 표준화: 계약 → 센서 설치 → DB 연동 → 교육 (4주 프로세스)
- 온실 구조 정보 수집 표준 양식 배포
- 확장 시 모델 재보정 프로세스 적용

### 연합학습 도입 (Phase 4)
- PySyft 또는 Flower 프레임워크 도입
- 농가 원시 데이터 비공유 + 모델 파라미터만 공유
- 계절별 작목 클러스터 구성
- 프라이버시 보호 검증 및 농가 동의 절차

### WUR AGC 2026 참가 (Phase 3~4)
- WUR Autonomous Greenhouse Challenge 2026 사전 등록
- 방울토마토 AI 제어 알고리즘 개발
- WUR 연구진 접촉 및 데이터 공유 MOU 논의
- 글로벌 데이터·모델 접근 기회 확보
