# 역량 단계별 핵심 서비스 큐레이션 프로세스 (C19)

## 배경 — 왜 필요한가
KAASA SmartOS는 35+ 화면을 제공한다. 모든 농가에게 전부 노출하면 **역량에 맞지 않는 기능에 압도**된다.
스마트농업 현장컨설팅 결과보고서의 컨설턴트 총평도 농가를 단계로 구분하고
**"고도화 기술 전수보다 기본적인 데이터 측정·관수 밸런스부터"** 라고 권고했다.
→ 진단된 역량 단계에 맞춰 **핵심 서비스 3~5개만** 선별 제시하는 라우팅을 정립한다.

## 프로세스 (진단 → 단계 판정 → 서비스 큐레이션 → 다음 과제)
```
C17 종합진단(6대 도메인 점수·tier)
      │
      ▼  api/services/capability_router.build_capability()
역량 단계 판정 _stage_of()
  · 기반(센서<40 또는 데이터<40) 미충족 → 무조건 1단계(기본부터)
  · overall <45 → 1 / 45~64 → 2 / 65~79 → 3 / 80+ → 4
      │
      ▼
단계별 핵심 서비스 3~5개(딥링크+이유) + 다음 단계 진입 핵심 과제(진단 우선처방 상위 2)
      │
      ▼  진입점: C3 홈 배너 · C17 버튼 · 네비게이터(C19)
```

## 4대 역량 단계 × 핵심 서비스
| 단계 | 이름 | 슬로건 | 핵심 서비스 |
|------|------|--------|------------|
| 1 | **기반 구축기** | 측정 기반부터 | C16 기자재 등록 · C17 진단 · G2 환경 모니터링 · C18 현장문진 |
| 2 | **데이터 정착기** | 관수 밸런스·생육 기록 | G3 관수 Period · G4 생육측정 · C14 월간리포트 · C4 AI진단 |
| 3 | **정밀 제어기** | 정밀 제어·예측 | C3 의사결정 · G6 수확예측 · G5 병해경보 · F3 16일예보 |
| 4 | **경영 고도화기** | 수익·판로·환원 | C12 공동출하 · C9 벤치마킹 · C5 ERP · C7 데이터 보상 |

판정 기준은 **현장컨설팅 단계 모델**(기반구축→데이터측정→정밀제어→경영) 벤치마킹.
센서·데이터 기반이 약하면 종합점수가 높아도 1단계로 묶어 "기본부터" 원칙을 강제한다.

## 산출물
- `api/services/capability_router.py` — SERVICE_CATALOG(단계×서비스) + 단계 판정 + 진행도
- `GET /api/farms/{id}/capability` — 단계·핵심서비스·다음과제·진행도
- `screens/c19_capability.html` — 4단계 스테퍼·진행바·핵심서비스 카드·다음 과제
- 진입점: C3 홈 역량 배너, C17 진단 CTA, 네비게이터 C19 카드

## 폐루프
진단 점수가 오르면(C17 추세) 단계가 상승하고 **새 핵심 서비스가 열린다**.
다음 단계 과제 = 진단 우선처방 → 해결 → 재진단 → 단계 상승. 현장컨설팅 회차별 성장 모델과 동일.
