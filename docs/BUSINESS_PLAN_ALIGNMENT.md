# 사업계획서 → 앱(KAASA SmartOS / Farmingsight) 정합성 추출

> 출처: `1 사업계획서.hwp` — ㈜이암허브 「농식품 AI 응용제품 신속상용화 지원사업」
> 제품 정식명: **Farmingsight (AI 기반 스마트농업 수익·환경·생육 통합 운영 최적화 OS)**
> 목적: 계획서의 약속·구조를 추출해 현재 앱 구현과 대조하고, 적용할 항목을 도출.

## A. 계획서 핵심 구조 (추출)

### A-1. 6층 아키텍처 (L1~L6)
| 레이어 | 역할 | 앱 대응 |
|--------|------|---------|
| L1 현장 | 센서 1분 수집(온·습·CO₂·EC·pH·LED·에너지) | KaasaData WS/센서 ✅ |
| **L2 Edge** | **이기종 통합 — 표준 스키마 정규화** | **C16 기자재+canonical 매핑 ✅(상용화 지표①)** |
| L3 플랫폼 | 저장·외부결합(기상·도매가·전기요금) | KAMIS·ASOS·ET₀ 연동 ✅ |
| L4 AI 에이전트 | 30초 빠른 자동제어 | G2 권고/제어모드(부분) ◑ |
| L5 LLM/RAG | 대화형 조언(농진청·병해DB 검색) | C13 챗봇(키 주입 시) ◑ |
| L6 제어·알림 | 복합환경제어기 명령·알림 | device_alert·연동배지 ◑ |

### A-2. 일일 6단계 운영 로직 ★ (P1~P6와 정확히 일치)
계획서: **일출 전 준비 / 오전 광량상승 / 정오 고광·고온 / 오후 광량하강 / 일몰 후 회복 / 야간 안정**
→ 앱 `data.js` PERIODS **P1~P6** 와 1:1 대응 ✅ (이번 세션에서 P6 추가로 완성)

### A-3. 다층형 시간창
실시간 – 전일 – 최근7일 – 최근14일 – 작기누적 – 향후7일 – 향후14일 (기능별 차등 적용)
→ 앱: 실시간(WS)·7일 분석·예보 ✅ / 14일·작기누적 일부 ◑

### A-4. 핵심 AI 4시나리오
1. **AI 에이전트(빠른 루프)**: 룰엔진+ML, LED 스펙트럼 자동제어, 에너지 자동절감(10~17시 20~50%↓) — DecisionDeck/권고 ◑
2. **LLM/RAG**: UC1~UC10 (이상설명·병해진단·작기보고서·신품종·결정설명·출하전략·ROI·에너지·수자원·포트폴리오)
3. 비전(병해 영상진단) ○
4. 종합진단·업그레이드 추천 AI ○

### A-5. 5대 농가 핵심문제 → 해결 → 예상효과
| 문제 | 해결 | 효과 |
|------|------|------|
| ① 에너지비용(경영비 30~40%) | 시간대별 요금 자동 절감 | 연 350~400만원 |
| ② 수확량·품질 편차 | LED 파장 자동·병해 72h 전 경고 | 수율 +25~30%, 당도 +1.2Brix |
| ③ 수익을 월말에야 앎 | 파종~수확 비용 실시간 소득률 | 즉시 의사결정(C5 ERP ✅) |
| ④ 데이터→의사결정 단절 | 운영 OS로 판단·실행·검증 통합 | DecisionDeck ✅ |
| ⑤ 이기종 설비 편차 | 표준화+물리 캘리브레이션 | C16 ✅(캘리브레이션 ◑) |

### A-6. 정량 성과지표
- 상용화 **2건**: ① 이기종 통합 ② 스마트농업 OS Agent  ← C16 + DecisionDeck가 직접 대응
- 매출 국내 3,826백만 / 수출 USD 3.64M, 투자 300백만
- 사업모델: SaaS 과금·조직형 패키지·ROI 리포트 (등급차등·C12·C14 ✅)

### A-7. 차별점(모방난이도↑)
물리적 성능 캘리브레이션(센서 오프셋·유량/압력·**액추에이터 응답시간·제어명령-실반응 편차**), 종합진단·업그레이드 추천, 시설·노지 확장(YAML 기반), 농장 운영 프로파일 맞춤 레시피.

## B. 적용할 항목 (앱 반영 권고)

### 즉시 적용 (이미 구조 보유, 소규모 보강)
1. **C13 챗봇에 UC1~UC10 활용사례 칩** 노출 — 사용자가 질문 유형을 바로 선택. (RAG 출처 배지: 농진청·병해DB)
2. **C16 물리 캘리브레이션 확장** — datapoint에 `actuator_response_s`(액추에이터 응답시간), `cmd_feedback_offset`(제어명령-실반응 편차) 필드 추가 (현재 scale/offset 보유 → 차별점 A-7 충족)
3. **P1~P6 공식 명칭 정렬** — 계획서 용어(광량상승/고광고온/광량하강/회복/안정) 병기

### 중기 (신규 화면/기능)
4. **종합진단·업그레이드 추천** 화면 — 장비상태·데이터품질·운영성숙도·병목 분석 → 개선 우선순위·ROI (C16/C4 확장)
5. **AI 에이전트 빠른루프 표면화** — 에너지 자동절감(10~17시), LED 스펙트럼 단계자동 카드
6. **다층 시간창** 14일·작기누적 뷰 보강

### 사업·정책 정합
7. 상용화 2건(이기종통합·OS Agent)·국민체감활동(시연·확산)·SaaS 반복매출 모델을 C14 리포트/오버뷰에 KPI로 표기
