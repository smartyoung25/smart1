# 스마트팜 소득조사표 — 현행 현안 vs 개선 방향 대조 및 활용방안
> 2026-08-04 · 근거: 농진청 소득조사표 4작목(딸기 류창영·방울 박경종·완숙 김선환·참외 강석구, 각 900㎡)
> 실측 대조 + CAPEX/OPEX 체계화(scripts/_build_capex_opex_taxonomy.py)·비용모델 연동(models/capex_cost.py)

## 0. 요약
현행 조사표는 **투자비(CAPEX)를 "상각비 2줄"로만** 담고 있어 무엇을·얼마에·몇 년 쓰는 자산인지 추적할 수 없다.
개선안은 이를 **3계층 자산등록부(업체·성능·취득가·내용연수·정액감가상각) + OPEX 연동**으로 구조화하고,
비용모델·ERP에 자동 연결한다. 아래는 조사 과정에서 실제로 확인한 현안과 개선 대조다.

---

## 1. 현행 소득조사표 현안 (조사표에서 실제 확인)

| # | 현안 | 근거(조사표) | 영향 |
|---|------|-------------|------|
| 1 | **CAPEX가 집계 상각비 2줄뿐** | `소득분석2` R21~23: 상각비 = 대농구 675,000 + 영농시설 783,000 | 자산별 세분·취득가·업체·성능 부재 → 투자 분석 불가 |
| 2 | **샘플 템플릿이 실 데이터처럼 존재** | `소득분석2` 이름 "홍길동", 4작목 상각비 값 **완전 동일**(675k/783k) | 실 농가 투자비가 아님. 실 데이터는 `농가` 시트에 흩어짐 |
| 3 | **분류가 2종(대농구/영농시설)뿐** | 스마트팜 핵심 복합환경제어·양액기·센서·난방기가 별도 분류 없이 혼재 | 스마트팜 특성(자동화 설비) 미반영 |
| 4 | **감가상각 산출근거 불투명** | 취득가·내용연수·잔존율이 없어 상각비가 어떻게 나왔는지 추적 불가 | 재계산·검증·재투자 판단 불가 |
| 5 | **OPEX↔CAPEX 연동 단절** | 수리유지비·수도광열·임차료 시트는 있으나 대부분 0(미입력), 어느 자산이 어느 운영비를 유발하는지 매핑 없음 | 투자→운영비 파급 분석 불가 |
| 6 | **시설이 정성 코드로만** | `농가` 시설현황이 코드값(J=1,2, 설치유무 ○/×)만, 취득가·업체·사양 결측 | 정량 투자비 산출 불가 |
| 7 | **작목별 시설차이 미반영** | 참외=보온·차광·관수 미설치/고장, 완숙=측창·관수관비 없음 (실데이터), 그러나 상각비는 4작목 동일 | 작목별 CAPEX 차이가 소득에 안 잡힘 |

## 2. 개선 소득조사표 방향 (구축·연동 완료)

| # | 개선 | 산출물 | 현안 해소 |
|---|------|--------|----------|
| 1 | **3계층 자산등록부** — 대분류(영농시설/기자재/대농기구) > 중분류 > 세부품목 | CAPEX 계층 등록부 시트 | #1·#3 |
| 2 | **자산별 속성** — 업체(제조사)·성능·사양·취득가액·내용연수·잔존율·**정액감가상각(수식)** | 등록부 11열 | #1·#4·#6 |
| 3 | **표준 내용연수 명시** — 법인세법 시행규칙 별표·농진청 농기계 기준(유리온실 15~20/비닐 10~15/스크린 5~7/제어·관수 7~10/센서 5/대농기구 5~8) | 내용연수 표준 시트 | #4 |
| 4 | **OPEX↔CAPEX 연동 매트릭스** — 수리유지(시설/대농기구)·수도광열(제어·난방·관수)·임차·소모품 매핑 | OPEX-CAPEX 연동 시트 | #5 |
| 5 | **작목별 시설구성 실데이터** — ○설치 자산만 감가상각 대상, 작목 차등 | 작목별 시설 구성 시트 | #7 |
| 6 | **비용모델·ERP 자동 연동** — register 취득가 입력 → 정액감가상각·수리유지 자동계산 → 소득구조 반영 | `models/capex_cost.py`·`m4_cost`·`_compute_costs` | #4·#5 |
| 7 | **정직성** — 조사표 집계 상각비가 템플릿임을 명시, 견적 입력 전엔 `source=template`로 표기 | 전 산출물 | #2 |

### 대조 핵심 예시 (같은 항목이 어떻게 바뀌는가)

| 항목 | 현행 | 개선 |
|------|------|------|
| 영농시설 투자 | "영농시설 상각비 783,000" (한 줄) | 온실구조(취득12,000,000·내용연수12·잔존10%→연900,000)·천정보온스크린·차광스크린… 자산별 분해 |
| 감가상각 근거 | (없음) | `= 취득가액×(1−잔존율)÷내용연수` 수식 |
| 작목 차이 | 딸기=방울=완숙=참외 동일 | 참외(시설최소)→감가 94.5원/㎡ vs 딸기 135원/㎡ (시설완비도 차등) |
| 운영비 연결 | (없음) | 난방기→수도광열, 양액기→전기·물·양액소재, 시설→수리유지 |
| 소득 반영 | 상각비 수기 | ERP `/costs`에 "감가상각(투자비)"·"수리유지비" 자동 항목화 |

## 3. 향후 활용방안

1. **견적서 연동 자동화** — C16(기자재 등록) 업로드한 견적서·시방서에서 취득가·업체·사양을 추출해
   `api/data/capex/register.json`을 자동 채움 → 감가상각·수리유지 자동 산출. (수기 조사 부담 제거)
2. **투자 의사결정 지원** — 신규 CAPEX의 (연 감가상각 + 유발 OPEX 증분) vs (노무 절감·수율·품질 편익)을
   대조하는 ROI 시뮬레이션. 자동화 설비일수록 감가↑·에너지↑·노무↓의 상충을 정량화.
3. **재투자·교체 시점 관리** — 내용연수 만료 자산과 '고장' 자산(예: 참외 관수관비)을
   재투자(교체 CAPEX) vs 수리(OPEX)로 구분해 알림.
4. **작목·지역 표준 CAPEX 벤치마크** — 과업①(소득조사 20개소) 견적 축적 시 작목·규모·지역별
   표준 투자비·감가상각 벤치마크 구축 → 신규 진입농가 투자계획 근거.
5. **소득 모델 정합** — stage3(매출)·stage4(비용) 소득 검증에 실 감가상각·수리유지를 반영해
   "소득(매출−비용)" 정확도 향상. (현재 비용의 flat 고정비를 자산기반으로 대체)
6. **정책·보조사업 근거** — 스마트팜 투자 ROI·감가상각 구조를 표준화해 보조사업 심사·
   경영진단·CAPEX/OPEX 다년 손익분기 산정 자료로 활용.

## 4. 선행 조건 (개선안 완성)
- **자산별 취득가(견적)** 확보 — 현재 register는 내용연수·잔존율 표준만, 취득가는 「입력」 대기.
- 과업①에서 **견적서·시방서**를 조사 항목에 포함하면 개선안이 실데이터로 즉시 작동.
- 개인정보·영업정보(업체·단가) 취급 기준 확정.
