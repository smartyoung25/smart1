# UNIT_DICTIONARY — 농학 단위 사전 (화면 KPI 단위 고정)

> 목적: 화면별 KPI 단위·트리거를 **농학적으로 정확**하게 고정하고, 신규 화면 회귀를 방지한다.
> 비판 메모: "관수=시간단위" 전제는 코드상 이미 **광량 기준** — 시간은 폴백일 뿐.

## 관수 (G3 / data.js IRRIGATION_START / priva_irrigation.py)
| 항목 | 단위 | 기준 |
|---|---|---|
| 관수 시작 트리거 | **J/cm²(적산일사) 우선 → W/m²(순간) → 휴지시간 → 수분장력** | P3≈400 J/cm²(≈600 W/m²) 첫 배액. 시각은 폴백 |
| 일사 적산 | J/cm², MJ/m² (1 MJ/m² = 100 J/cm²) | Priva range 200→800 W/m² |
| 배액률 | % | P3 20~30, P4 20~35(허용~35·위험<15) |
| 급액/배액 EC | dS/m | 급액 2.5~3.5 |
| 급액 pH | — | 5.5~6.5 |
| 공급량 | ml/slab·day, mm/day, L/m²(P/I) | slab 0.15㎡ |
| 야간소실률 | % | 3~7 |

## 환경 (G2 / climate_plan.py)
| 항목 | 단위 | 기준 |
|---|---|---|
| 온도 | ℃ | 전략표(생육시기×구간) |
| 습도 | % | — |
| CO₂ | ppm | 800~1200 |
| VPD | kPa | 0.6~1.2(상태 0.4/0.6/1.5/2.0) |
| **DLI** | **mol/m²·d (PAR, ×4.57)** | 목표 작물별(딸기 ~10) |
| 24h 평균기온(HNT) | ℃ | 온도적산 ±2℃ 보정 |
| 구간 경계 | 일출·일몰(Open-Meteo) 동적 | 야간/일출/주간/일몰전 |

## 생육·시기
| 항목 | 단위 | 기준 |
|---|---|---|
| 생육시기 | **정식후 일수 + GDD(적산온도)** 병기 | 작물 기준온도별 |
| 수확량(M2) | kg/㎡(단위면적) → 총 kg | 면적 환산 |
| 목표수확량 | kg/10a(면적당) | C1 입력 |

## 경영·시장
| 항목 | 단위 |
|---|---|
| 원가·마진 | 원/kg |
| 소득률 | % |
| 매출·비용·이익 | 원(월) |
| 시세 | 원/kg (KAMIS) |

## 규칙
- 신규 KPI는 이 사전에 등록 후 화면 라벨에 단위 명시. 시간 기반 트리거 도입 금지(광량/적산 우선).
