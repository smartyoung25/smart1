# 노지 클러스터 작황 모니터링 (F8) — 무센서·위성/AI/기상

## 검토 배경 — 노지 3대 벤치마킹 원칙
기존 노지(F2 GIS·F5 원격탐사)는 **단일농가·필지 단위 NDVI 표시**에 머물렀다.
다음 세 원칙으로 확장:

| 원칙 | 구현 |
|------|------|
| ① **무센서 광역관리** (위성·AI·기상) | 개별 고가센서 없이 위성 식생지수 + 16일 기상으로 작물건강·스트레스·이상 모니터링. 위성 미연동 시 결정론적 프록시(필지ID 해시+기상보정), `source='satellite-proxy'`. Sentinel-2/팜맵 연동 시 `'sentinel-2'` 실측 전환 |
| ② **클러스터 관리** | 다수 필지(→다수농가·계약재배·정부사업·광역)를 클러스터로 집계 — 평균 NDVI·작황등급·**균일도**·이상필지 수 |
| ③ **진단→위치특정→실행알림** | 단순 지도가 아니라 **필지 위치 + 클러스터 평균 대비 정량편차(Δ%) + 심각도 + 실행지시(현장확인 원탭 기록)** |

## 데이터 흐름
```
/field/parcels (팜맵→Mock)  ┐
extended_weather 16일 ET₀·강수 ┼→ field_cluster.build_cluster()
/field/soil 토양수분(흙토람)   ┘        │
                                        ▼
필지별 NDVI(프록시) + 기상 수분스트레스 보정
  → 클러스터 평균·표준편차·균일도·작황등급
  → 위치특정 이상알림: Δ% 편차·심각도·실행지시
```

## 무센서 스트레스 산식
- 수분스트레스 = max(0, ET₀−강수)/ET₀ × 40 (%) — 7일 누적
- 고온일수 = 최고기온 ≥31℃ 일수
- 필지 NDVI 보정 = 기준(해시) − 0.12×수분스트레스 + (토양수분−55)/500

## 이상 판정(③ 위치특정 알림)
| 조건 | 유형 | 심각도 | 실행지시 |
|------|------|--------|----------|
| NDVI<0.50 또는 Δ≤−12% | 생육 저조 | 🚨 시급 | 현장 확인·관수/시비 점검 |
| 수분스트레스≥25% & NDVI<평균 | 수분 스트레스 | ⚠️ 주의 | 관개 우선 배정 |
| Δ≤−7% | 평균대비 편차 | ⚠️ 주의 | 생육 추세 관찰 |

각 알림 → `[현장 확인]`(F5 딥링크) + `[기록]`(RecordSheet→/activity kind=disease_check) 폐루프.
