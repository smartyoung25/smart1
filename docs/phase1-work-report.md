#### 🟡 MEDIUM — 신뢰도에 영향을 주는 항목

**④ 수익 최적화 엔진 — 단순 선형 스텁**  
`profit_optimizer.py`의 yield 예측 함수가 `temp_internal`에만 반응하는 단순 식.  
humidity, CO₂, EC, solar_rad 변경에 대한 수익 델타가 0으로 계산됨.

```python
def yield_predict_fn(env: dict) -> tuple[float, float]:
    temp = env.get("temp_internal", 22.0)
    bonus = max(0.0, 0.01 * (temp - 20.0))  # 온도만 반영
    return baseline_yield_kg_m2 + bonus, 0.6  # confidence 고정 0.6
```

**⑤ 비용 계수 placeholder**  
`profit_optimizer._COST_PER_UNIT`의 주석에 "placeholder values"라고 명시.  
CO₂ 시비 비용(0.5원/ppm·day)은 실제와 크게 다를 수 있음.

**⑥ GDD 파라미터 — 문헌값**  
수확 D-day 계산에 사용되는 `base_temp_c`, `gdd_to_first_harvest`가  
실측 데이터 없이 문헌(교과서) 값. 품종·지역별 편차 미반영.

| 작목 | 기준온도 | 첫 수확 GDD | 출처 |
|------|---------|-----------|------|
| 딸기 | 6°C | 450 GDD | 문헌값 (미보정) |
| 방울토마토 | 10°C | 600 GDD | 문헌값 (미보정) |
| 참외 | 12°C | 700 GDD | 문헌값 (미보정) |

**⑦ 수확량 신뢰구간 미표시**  
표준편차가 평균의 50~75%에 달하는 데이터(오이, 완숙토마토)임에도  
API 응답에 confidence_interval 없이 단일 점 추정값만 반환.

**⑧ In-memory 저장소**  
수동 환경 입력(`_MANUAL_ENV`)과 실제 비용 입력(`_MANUAL_COSTS`)이  
서버 재시작 시 완전 소실. 프로덕션 사용 불가 구조.
