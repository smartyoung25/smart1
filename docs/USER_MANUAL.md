## 1. 시스템 개요

### 무엇을 해결하나 (5대 농가 문제)
1. **에너지 비용 과다** — 시간대별 요금 자동 절감(10~17시), 연 350~400만원 절감 목표
2. **수확량·품질 편차** — LED 파장·환경 자동제어, 병해 72h 사전경고
3. **수익을 월말에야 앎** — 파종~수확 비용 실시간 소득률
4. **데이터→의사결정 단절** — 판단·실행·검증 통합(DecisionDeck 원탭)
5. **무센서 노지 광역관리 어려움** — 위성·기상·AI로 고가센서 없이 작황 진단

### 6층 아키텍처
| 층 | 내용 |
|----|------|
| 센서/수집 | 환경센서·관수·생육·수확 실측, MQTT |
| 데이터 | canonical 정규화 → parquet, PostgreSQL |
| 모델 | M1 생육 · M2 수확량 · M3 가격 · M4 비용 · M5 병해 + 평년기상(ERA5) |
| 의사결정 | DecisionDeck(이상감지+추천+처방+원탭 실행) |
| 운영/경영 | 환경·관수·수확·출하·수익·진단·역량 |
| 학습 환원 | 이행→축적→재학습→보상 폐루프(연합학습 준비) |

### 모델 계층 (3단 폴백)
- **Layer 0** 농진청 표준모델(정적 기준값) → **Layer 1** KAASA 현장학습모델(API 추천) → **Layer 2** 내 농장 맞춤보정(farm_corrections)
- 화면은 항상 사용 가능한 최상위 층을 자동 선택해 표시.

## 2. 시작하기

### 접속
- **웹**: 공개 데모 URL(퀵터널, `deploy/cloudflare/current_url.txt`에 최신 주소) 또는 `http://localhost:8000`
- 진입점: `/intro`(소개) · `/smartos`(전체 네비게이터)

### 로그인
- 데모 계정 **admin / 1250** — 대부분 화면이 **자동 로그인**되어 직접 입력 불필요.
- 회원가입은 **C0 회원가입**(역할 선택·계정·관심기능).

### PWA(앱) 설치
- 모바일 브라우저 접속 → **Android(Chrome)** 메뉴 "홈 화면에 추가" / **iOS(Safari)** 공유 "홈 화면에 추가"
- 설치 시 전체화면(standalone) 앱처럼 동작. 오프라인 시 상단 배너로 연결상태 안내.

### 등급(요금제)
- basic / smart / pro / enterprise 4계층. 상위 기능은 잠금 배지·오버레이로 표시되며 업그레이드 시트에서 전환.
- 공개 데모는 **읽기 전용** — 조회는 모두 되고, 쓰기·관리자·결제 기능은 비활성(403).

## 4. 신규 농가 온보딩

흐름: **C0 회원가입 → C1 농장 세팅 → 🔐 C2 데이터 동의 → 운영 진입**

- **C0 회원가입**: 역할(시설/노지)·계정·관심 기능 선택.
- **C1 농장 기본 세팅**(7단계 위저드): 작물·재배환경·관개방식 입력 → 저장 시 **시설/노지 자동 분기**.
  - 저장 후: **🔐 데이터 활용 동의(권장)** → 이후 **시설=C16 기자재 등록 / 노지=F8 클러스터 작황**으로 안내.
- **C2 데이터 공개·활용 동의**: 활용 모드 + 항목별 토글. "내 데이터로 AI가 학습"하는 범위를 직접 설정. 저장 후 **계속 →** 로 온보딩 이어감.

## 6. 온실 운영 (G1~G6)

### G1 — 온실 홈
온실 To-do · 핵심 KPI(온도·배액률·수확 D-day) · DecisionDeck · G2~G6 서브링크.

### G2 — 환경·기후 제어
- **실내 환경**(온도·습도·CO₂·일사·VPD) 실시간 · **환경 추이** 그래프
- **제어 모드 4단계** · **AI 에이전트(30초 빠른 루프)** 자동 절감 추천
- **외기 현황(ASOS)** · **★평년 대비 외부기상 카드(ERA5 5년)** — 현재 외기 vs 평년 편차로 냉난방 부하 시사
- **에너지 사용·요금**(시간대별 절감)

### G3 — 관수·양액 Period 관리 ★핵심
하루 관수를 **P1~P6 Period**로 관리(Grodan/Priva 일일 WC·EC 곡선):
| Period | 시간 | 핵심 |
|--------|------|------|
| P1 | 일출 전 | 야간 dry-back 확인·첫 관수 산정 |
| P2 | 첫 관수 | 염류 세척·EC↓ |
| P3 | 오전 첫 배액 | 배액 EC 최저 |
| P4 | 정오 고부하 | 함수율 64~65% 유지 |
| P5 | 오후 dry-down | 조기 종료·생식생장 유도 |
| P6 | 야간 | dry-back·뿌리 산소화 |
- **트리거는 일사 적산(J/cm²) 우선**, 시각은 폴백.
- 급액/배액 EC·pH·배액률(목표 20~30% 밴드 음영)·급액량 표시. **작물별로 값이 다릅니다**(딸기 저EC ~2.0 vs 토마토 ~3.8).
- AI 추천 → 원탭 적용 → 기록.

### G4 — 생육 모델
수확 D-day · 생육단계 · M1 생육/M2 수확예측(신뢰도·데이터 품질 등급 표시).

### G5 — 병해·품질
M5 병해 위험도 · 결로시간·IPM 조기경보 · 이상값 · 방제 조언.

### G6 — 수확·유통
출하 채널 비교 · 시나리오 · 수익성(AI 출하 추천).

## 7. 노지 운영 (F1~F8)

### F1 — 노지 홈
필지 지도 · 기상 ET₀ · 노지 To-do · **노지 현장 컨설팅 배너**(종합진단·현장문진·역량·전문가) · F2~F8 서브링크.

### F2 — 필지 GIS
필지 경계·구획. 농장이 제주면 **🟢 팜맵 실데이터**, 아니면 Mock 배지.

### F3 — 기상·재해
- 7일 예보(KMA 실측) · **16일 장기예보(Open-Meteo)** · 작업 가능 시간대
- **★평년 대비 기상 카드(ERA5)**: 평년 4지표 + 향후 16일 평년 대비 편차(생육·저온/고온 시사).

### F4 — 토양수분·관개
ETc · 관개 우선순위 · 필지별 토양수분. 제주면 **🟢 흙토람 토양검정 실데이터**, 아니면 Mock.

### F5 — 원격탐사
NDVI·NDRE·열화상(위성 식생지수). 미연동 시 결정론적 프록시.

### F6 — 병해충·방제
M5 병해 · 방제 윈도우(살포 적기).

### F7 — 노지 수확·유통
필지별 수확 · 공동출하 연계.

### F8 — 클러스터 작황 모니터링 ★무센서 광역
- **무센서**: 위성 식생지수(미연동 시 프록시)+16일 기상 스트레스
- **클러스터 집계**: 평균 NDVI · 작황등급 · **균일도** · 이상 필지
- **위치특정 알림**: 필지 위치 + 클러스터 평균 대비 정량편차(Δ%) + 실행지시(원탭 기록)
- **★평년 대비 작동진단**: 16일 예보가 평년에서 크게 벗어나면(±3℃·강수±50%) **광역 이상기상**으로 판정 → 이상 필지 알림 **심각도 상향**(주의→시급)+🌡️칩+배너("개별 관리 아닌 광역 기상 영향").

## 8. 진단·컨설팅·역량

### C17 — 시스템 종합진단
6대 영역(센서·구동기·재배·경영노동·유통·데이터) 점수 + 우선순위 처방(ROI) + 회차별 추세 스파크라인. 결과는 C4 컨설팅·C14 리포트로 연결.

### C18 — 현장컨설팅 문진
RDA 체크리스트 30항목(원수·필터·RO·유황훈증·병해충·인증 등 텔레메트리 외 항목 현장 점검). 입력 시 C17 진단이 **텔레메트리:현장 = 50:50**으로 정밀화.

### C19 — 역량별 핵심 서비스
진단 → **4단계 역량**(기반구축/데이터정착/정밀제어/경영고도화) 판정 + 단계별 핵심서비스 3~5개 큐레이션(과잉 노출 방지). 센서·데이터 미충족 시 1단계 강제.

### C4 — AI 진단
진단 점수 · 추천 Accordion · 전문가 예약(진단결과 자동 첨부).

## 10. AI·학습·챗봇

### C6 — AI 학습
- **학습 파이프라인**: 수집 → ETL → **🛰️ 외부기상 보강(ERA5)** → 모델 학습 → 게이트 검증
- **배포 게이트·임계점**: 통과 기준 **MAPE ≤ 35% AND R² ≥ 0**. 챔피언/챌린저 자동선택(M2 MAPE 5%p↓ 또는 M1 R²+0.02 시 자동 배포, 미달 rollback).
- **M2 수확량 게이트 표**: 작물별 MAPE·R²·통과/탈락. 딸기는 **🛰️ERA5↑**(외부기온 보강으로 R² 0.19→0.30 개선).

### C13 — AI 챗봇(영농 비서)
농장 데이터 기반 의도응답(관수·환경·에너지·수확·수익·병해·진단·역량). LLM 키 주입 시 생성형 고도화, 미주입 시 rule 기반.

### 평년 기상(ERA5) — 26작물
G2(온실)·F3(노지)·F8(클러스터)에서 작물·월별 평년값(기온·일사·강수·GDD)을 자동 표시. [14절 참조].

## 11. 시스템·연동·관제

### C16 — 시설 기자재·이기종 통합
장비 등록(제조사·프로토콜) → 데이터 포인트를 **표준 변수(canonical)** 로 매핑 → 화면·AI가 기종 무관 동일 사용. 물리 캘리브레이션(명령-실반응 편차).

### C8 — 이기종 연동
프로토콜·표준변수 체계·제어 성공률.

## 16. 용어집

- **Period(P1~P6)**: 하루 관수를 6단계로 나눈 시간창(우선순위 아님).
- **배액률(Drain %)**: 급액 대비 배출량 비율. 목표 20~30%.
- **EC**: 양액 전기전도도(염류 농도, dS/m).
- **VPD**: 수증기압 결손(증산·결로 지표, kPa).
- **DLI/일사 적산**: 누적 광량(J/cm²) — 관수 트리거 기준.
- **NDVI**: 위성 식생지수(작물 건강·활력).
- **GDD**: 생육도일(작물별 기준온도 이상 적산 열량).
- **MAPE / R²**: 모델 정확도 지표(낮은 MAPE·높은 R²가 우수).
- **DecisionDeck**: 이상감지+추천을 원탭 실행으로 묶은 의사결정 카드.
- **canonical 변수**: 기종 무관 표준화된 데이터 변수명.

## 17. FAQ·문제해결

**Q. 가격/일부 데이터가 안 보여요.**
A. 공개 데모는 읽기전용이라 일부 관리자 데이터는 대체 경로(예: 농장 작목 KAMIS 시세)로 표시됩니다. 정상입니다.

**Q. 토양·필지가 "Mock"으로 떠요.**
A. 흙토람·팜맵 실데이터는 현재 **제주 지역**만 적재돼 있습니다. 제주 농장으로 전환하면 🟢 실데이터로 바뀝니다.

**Q. 작물을 바꿨는데 관수(G3)가 비어요.**
A. 작물별 관수 샘플이 있는 데모 농장(오이·방울토마토·딸기·완숙토마토·파프리카)에서 동작합니다.

**Q. 공개 URL이 안 열려요.**
A. 무료 퀵터널은 서버 재시작 시 주소가 바뀝니다. 최신 주소는 `deploy/cloudflare/current_url.txt`에서 확인하세요.

**Q. 저장/적용 버튼이 403이에요.**
A. 공개 데모는 읽기전용(쓰기·관리자 차단). 실서비스 환경에서는 정상 동작합니다.

**Q. 딸기 수확 예측이 낮게 나와요.**
A. 딸기 M2 모델은 데이터 한계로 보수적입니다(신뢰도·데이터 품질 등급 표기). ERA5 외부기상 보강으로 정확도를 개선했습니다.
