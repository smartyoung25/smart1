```python
# 수정 전 (누수: 테스트 연도 포함 전체 평균)
farm_global_mean = prod_ann.groupby("farm_id")["yield_per_m2"].transform("mean")
prod_ann["farm_quality"] = farm_global_mean.fillna(global_mean)

# 수정 후: farm_quality 컬럼 자체 제거
# farm_yield_hist_mean이 동일한 정보를 expanding().mean().shift(1)로 안전하게 포착
# _ALWAYS_INCLUDE 리스트에서도 farm_quality 제거
```

**② `train_multi_crop_pipeline.py` — `train_model()` 과적합 방지**

```python
# 수정 전 (과적합)
xgb_m = xgb.XGBRegressor(n_estimators=300, max_depth=4, ...)
xgb_m.fit(X, y)  # early stopping 없음, log1p 없음

# 수정 후: TimeSeriesSplit CV + early stopping + log1p + 강화 정규화
# - TimeSeriesSplit(n_splits=2~4)
# - early_stopping_rounds=15~30 → n_estimators 자동 결정
# - log1p 타겟 변환 + expm1 역변환
# - max_depth=3, reg_alpha=1.0, reg_lambda=5.0
```

**③ `predict()` 함수 — log_transform 지원 추가**

   구버전 `_get_engine()` 의 치명적 결함 두 가지:
   - `_ENGINE = create_engine(...)` 을 연결 테스트 **이전**에 저장 → 실패해도 `_ENGINE` 에 broken engine 잔류
   - `_ENGINE_FAILED` 플래그 없음 → 두 번째 호출에서 broken engine 반환
   
2. **`get_user_by_username` 예외 핸들러 구버전**  
   구버전 pyc 의 예외 핸들러가 `return None` (dev fallback 없음) → `issue_token()` 에서 `user is None` → 401

3. **`DATABASE_URL` 테스트 환경 오염**  
   `api/main.py` 의 `load_dotenv()` 가 `.env` 에서 `DATABASE_URL=postgresql://...@db/smartfarm` 로드  
   → `_get_engine()` 이 실 DB 연결 시도 → 연결 실패 → 위 두 버그 발동
