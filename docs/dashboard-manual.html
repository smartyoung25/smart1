스마트팜 AI 플랫폼
경영자 대시보드

농장 환경 데이터를 실시간으로 모니터링하고, AI가 수익을 극대화하는 조치를 금액으로 제안하는 통합 관리 도구입니다. IoT 센서가 없는 농가도 수동 입력만으로 동일한 AI 추천을 받을 수 있습니다.

버전: v1.0
대상: 농장 경영자
접속: http://localhost:3000
최적 환경: 모바일 · 태블릿 · PC

1개요 및 주요 기능

이 대시보드는 스마트팜 경영자가 하루 중 언제 어디서나 농장 상태를 파악하고, AI가 제안하는 환경 조정 조치를 실행할 수 있도록 설계됐습니다.

⭐
AI 수익 추천
온도·습도·CO₂ 등 환경 조정으로 얼마나 더 벌 수 있는지 금액으로 제시 (예: "온도 2°C 올리면 +14만원")
🌡
실시간 환경 모니터
온도·습도·CO₂·EC·일사량·지온을 실시간 표시. IoT 미구축 농가는 수동 입력 가능
📅
수확 예측
AI가 현재 GDD(적산온도)와 생육 데이터로 예상 수확일·수확량을 D-day로 표시
💰
수익 현황
KAMIS 실시간 단가 × 예상 수확량 × 면적으로 이번 달 예상 순이익 자동 계산
📊
비용 분석
전기·용수·난방·인건비·영양제·농약 항목별 월 비용과 절감 인사이트 제공
💬
AI 상담
농장 데이터를 기반으로 재배 관리, 환경 조정, 수익 향상 방법 등을 자유롭게 질문

2화면 레이아웃 (기기별)

대시보드는 사용하는 기기 크기에 따라 레이아웃이 자동으로 바뀝니다.

📱 모바일 (화면 너비 639px 이하)
  • 화면 하단에 탭 바가 고정됩니다 (AI추천·환경·수확예측·수익·비용분석·AI상담).
  • 상단 바에는 농장명·작물명·알림·수확D-day·이번달수익 pill이 표시됩니다.
  • 콘텐츠는 세로 1열 배치입니다.
  • 글자 최소 크기 16px — 60대 경영자도 편하게 읽을 수 있습니다.
💻 태블릿 (640px — 1023px)
  • 상단 바 안에 가로 스크롤 탭 메뉴가 나타납니다.
  • 하단 탭 바는 사라집니다.
  • 콘텐츠는 중앙 정렬 단일 열로 표시됩니다.
🖥 PC·데스크탑 (1024px 이상)
  • 화면 왼쪽에 사이드바가 고정됩니다 (농장정보 + 네비게이션 + 빠른 현황).
  • 상단 탭 메뉴는 사라지고 사이드바에서 메뉴를 선택합니다.
  • 콘텐츠 영역은 최대 900px, 넓은 여백으로 가독성이 높습니다.
  • 사이드바 하단에 이번달 수익·알림 수·수확 D-day가 항상 표시됩니다.
💡
한 URL로 어디서나 접속
현장에서는 스마트폰으로, 사무실에서는 PC로, 같은 주소(http://localhost:3000)에 접속하면 화면 크기에 맞는 레이아웃이 자동 적용됩니다.

3상단 바 안내

화면 최상단에 항상 표시되는 고정 바입니다.

항목의미동작
농장명 · 작물명 현재 선택된 농장과 재배 작물 클릭 없음 (정보 표시용)
IoT 미구축 뱃지 해당 농장에 IoT 센서가 없음을 표시 환경 탭에서 수동 입력 필요
알림 N pill 현재 임계값 초과·이하 알림 건수 클릭 시 알림 패널 펼치기/접기
수확 D-N pill 예상 수확일까지 남은 일수 클릭 없음
NNN만원 pill 이번 달 예상 순이익 (작물별 계산) 클릭 없음

4메뉴 ① AI 추천

AI가 현재 농장 환경 데이터를 분석해 수익을 가장 높일 수 있는 환경 조정 조치를 순위로 제안합니다.

히어로 카드 (1순위 추천)

구성 요소
  • 행동 설명 — 예: "내부 온도를 22°C → 24°C로 올리세요"
  • +N만원 — 이 조치로 증가하는 예상 수익
  • 신뢰도 바 — AI 예측 신뢰도 (0~100%)
  • [지금 적용] 버튼 — 농가 Tier에 따라 동작이 다릅니다 (아래 참고)

[지금 적용] 버튼 동작 (Tier별)

Tier농가 유형버튼 클릭 결과
Tier 1 수동 IoT 미구축, 수동 조작 체크리스트 화면 출력 (조작 순서 안내)
Tier 2 반자동 IoT 구축, 반자동 제어 승인 확인 모달 → 확인 시 액추에이터 자동 제어
Tier 2+ 자동 완전 자동화 즉시 실행 + 완료 알림
⚠️
환경 데이터 없이는 추천이 나타나지 않습니다
IoT 미구축 농가(farm_005)는 환경 탭 → 수동 입력을 먼저 완료해야 AI 추천이 나타납니다. 입력값이 저장되면 자동으로 AI 추천 탭으로 이동합니다.

5메뉴 ② 환경 모니터

IoT 구축 농가

센서 데이터가 실시간으로 표시됩니다. 6가지 환경 지표를 카드로 확인할 수 있습니다.

지표명단위적정 범위 (예시)
내부 온도°C작물별 상이 (딸기: 18~22°C)
내부 습도%60~70% (작물별 상이)
CO₂ 농도ppm800~1,200 ppm
일사량W/m²200~800 W/m²
EC (전기전도도)dS/m1.5~2.8 dS/m
지온°C18~22°C

IoT 미구축 농가 — 수동 입력

직접 측정하거나 육안으로 확인한 값을 입력합니다.

  1. 환경 탭 이동
    하단 탭 바(모바일) 또는 사이드바(PC)에서 환경을 누릅니다.
  2. 값 입력
    온도·습도·CO₂·일사량·EC·지온 중 알고 있는 항목만 입력합니다 (모든 항목 필수 아님).
  3. 저장
    [환경값 저장] 버튼을 누르면 값이 서버에 저장되고 AI 추천 탭으로 자동 이동합니다.
📝
입력 범위 안내
각 항목마다 유효 범위가 표시됩니다. 범위를 벗어나면 빨간 테두리와 오류 메시지가 나타납니다. 정확한 값을 모를 경우 해당 항목을 빈칸으로 두어도 됩니다.

6메뉴 ③ 수확예측

AI 모델(M2·M3)이 현재 생육 데이터를 기반으로 예상 수확일과 수확량을 예측합니다.

항목설명
예상 수확일가장 가능성 높은 수확 날짜 (D-day)
예상 수확량kg/m² 단위 예측치 + AI 신뢰도 (%)
누적 GDD적산온도 (°C·일). 목표 GDD 대비 달성률로 성숙도 판단
🌱
GDD(Growing Degree Days)란?
작물이 하루 동안 받은 온도 합계입니다. 예를 들어, 딸기의 목표 GDD가 1,200°C·d이고 현재 842°C·d라면 목표의 70%를 달성한 상태입니다. 온도를 높이면 GDD가 빠르게 쌓여 수확일을 앞당길 수 있습니다.

7메뉴 ④ 수익 현황

KAMIS(농산물 유통정보시스템) 실시간 도매가와 AI 예측 수확량으로 이번 달 수익을 자동 계산합니다.

항목설명계산식
KAMIS 단가현재 도매 시장 거래가— (실시간 데이터)
예상 매출이번 달 총 판매 금액단가 × 예상 수확량 × 면적(m²)
예상 비용이번 달 총 운영 비용비용분석 탭의 월 총 비용
예상 순이익매출 — 비용예상 매출 − 예상 비용

월 비용 요약 미리보기

수익 탭 하단에 비용분석 요약이 표시됩니다. 상세 보기 → 링크를 누르면 비용분석 탭으로 이동합니다.

8메뉴 ⑤ 비용 분석

월 운영 비용을 6개 항목으로 분류해 보여주며, 각 항목의 계산 근거와 절감 방법을 안내합니다.

비용 항목

항목계산 기준단가
⚡ 전기료 일 사용량(kWh) × 30일 × 단가 105원/kWh (농업용 갑종)
💧 용수비 일 사용량(m³) × 30일 × 단가 700원/m³ (농업용 평균)
🔥 난방비 일 난방에너지(kWh) × 30일 × 단가 85원/kWh (가스 열량 환산)
👤 인건비 일 작업시간 × 30일 × 시급 12,000원/시간 (2025 농업 기준)
🌱 영양제·비료 일 비용 × 30일 작물·면적별 상이
🧪 농약·방제 일 비용 × 30일 작물·면적별 상이

항목별 비용 바 차트

비용이 높은 항목부터 내림차순으로 가로 바 차트가 표시됩니다. 각 항목의 단위 레이블(예: "192kWh/일 × 30일 × 105원/kWh")을 통해 어떻게 계산됐는지 확인할 수 있습니다.

절감 인사이트

세 가지 주요 절감 방법이 자동으로 제안됩니다:

  • 전기 절감 — LED 보광 타이머 최적화로 10% 절약 시 예상 금액
  • 용수 절감 — 점적관개 + EC 정밀제어로 15% 절약 시 예상 금액
  • 난방 절감 — 보온커튼 야간 운영으로 20% 절약 시 예상 금액
💡
탄소 배출량 자동 계산
전기 사용량 KPI에 탄소 배출량(kg CO₂)이 자동 계산됩니다. 계수: 0.459kg CO₂/kWh (한국 전력 배출계수 2024 기준).

9메뉴 ⑥ AI 상담

현재 농장 데이터(환경·알림·수익·수확예측)를 기반으로 재배 관련 질문에 답변하는 채팅 인터페이스입니다.

사용 방법

  1. 하단 입력창에 질문 입력
    자유롭게 입력하거나 화면에 표시된 제안 칩을 눌러도 됩니다.
  2. Enter 키 또는 전송 버튼
    Shift+Enter로 줄바꿈, Enter 단독으로 전송됩니다.
  3. 응답 확인 + 후속 질문
    AI 응답 아래 후속 질문 칩이 나타납니다. 클릭하면 바로 전송됩니다.

질문 예시

🔔
알림 확인
"현재 알림 확인해줘" → 현재 발생 중인 알림과 임계값을 알려줍니다
📅
수확 일정
"수확일이 언제야?" → 예상 수확일·D-day·GDD 현황을 설명합니다
💰
수익 분석
"이번 달 수익 얼마야?" → 단가·수확량·비용을 포함한 순이익 계산을 보여줍니다
🌡
환경 관리
"온도 몇 도가 좋아?" → 작물별 최적 온도 범위와 관리 팁을 알려줍니다
🤖
AI API 연결 준비 중
현재는 농장 데이터를 참조하는 규칙 기반 응답을 제공합니다. 향후 GPT-4o 또는 Claude API 연결 시 더 정교한 자연어 답변이 가능합니다. 상단 배너에서 현재 모드를 확인할 수 있습니다.

10알림 대응 방법

환경 지표가 작물별 임계값을 초과하거나 미달할 경우 상단에 알림이 표시됩니다.

알림 심각도

등급색상의미대응 속도
위험 빨간색 즉시 조치가 필요한 심각한 이상 (낙과·병해 위험) 즉시 (당일)
주의 노란색 방치 시 품질 저하·비용 증가 가능 24시간 이내
정보 파란색 참고 정보, 즉각 조치 불필요 여유 있을 때

알림 패널 열기

상단 바의 알림 N 버튼을 클릭하면 알림 패널이 펼쳐집니다. 각 알림에는 현재값과 기준값이 함께 표시됩니다.

🚨
위험 알림 발생 시 즉시 확인하세요
특히 온도 초과(착과 불량), 습도 초과(보트리티스 곰팡이), EC 이탈(뿌리 장해) 알림은 당일 조치가 수확량에 직접 영향을 줍니다. AI 상담 탭에서 조치 방법을 질문할 수 있습니다.

11농가 자동화 등급 (Tier)

농가의 IoT·자동화 수준에 따라 AI 추천 적용 방식이 달라집니다.

Tier 1
수동 농가 — IoT 미구축 또는 수동 제어. 환경값을 직접 측정해 입력. AI 추천 적용 시 체크리스트(순서별 조작 안내) 출력.
수동
Tier 2
반자동 농가 — IoT 구축, 일부 자동화. [지금 적용] 클릭 → 승인 확인 모달 → 확인 시 액추에이터(난방기·환기팬·CO₂ 발생기 등) 자동 제어.
반자동
Tier 2+
완전 자동 농가 — 모든 환경 장치 자동 제어. 임계값 이탈 감지 즉시 자동 조정. 완료 후 푸시 알림 발송.
자동

12비용 절감 전략

비용 분석 탭의 인사이트를 실제 운영에 적용하는 방법입니다.

⚡ 전기료 절감 (평균 10~15%)

  • LED 보광등 타이머를 일출·일몰에 맞게 자동 설정
  • 계절별 일조 시간 변화에 따라 타이머 주기적 재설정
  • 환기팬을 온도·습도 연동 자동 제어로 불필요한 가동 줄이기
  • 농업용 경부하 요금제(심야 시간대) 활용 — 야간 작업 전환

💧 용수비 절감 (평균 15~20%)

  • 점적(드립) 관개로 엽면 접촉 없이 뿌리 부위만 공급
  • EC 센서 기반 정밀 관비로 과잉 공급 방지
  • 배액 회수 시스템 도입으로 배양액 재사용
  • 오전 관비 집중으로 야간 과습 예방

  • 보온커튼(열차단 다중 피복) 야간 운영

13자주 묻는 질문

Q. 데이터가 '불러오는 중...'에서 멈춥니다

API 서버가 실행 중인지 확인하세요. 터미널에서 bash scripts/start_api.sh 8010을 실행 후 새로고침하세요.

Q. AI 추천이 나타나지 않습니다 (IoT 미구축 농가)

환경 탭으로 이동해 현재 농장 환경값을 수동으로 입력하고 저장하면 AI 추천이 생성됩니다.

Q. 수익 금액이 이상합니다

수익은 예상 수확량 × KAMIS 단가 × 면적 − 월 비용으로 계산됩니다. KAMIS 단가는 시장 변동에 따라 자동 갱신됩니다. 작물별 단가와 면적이 맞는지 관리자에게 확인하세요.

Q. 비용 분석의 단가는 어떻게 정해지나요?

전기 105원/kWh(농업용 갑종 기본), 용수 700원/m³(농업용 지하수 평균), 난방 85원/kWh(LPG·도시가스 열량 환산), 인건비 12,000원/시간(2025 농업 기준)입니다. 실제 단가가 다를 경우 관리자 대시보드에서 수정할 수 있습니다.

Q. AI 상담이 엉뚱한 답변을 합니다

현재 AI 상담은 규칙 기반 응답(stub 모드)으로, 키워드에 따라 미리 작성된 농업 지식을 응답합니다. 향후 GPT-4o·Claude API 연결 시 더 정교한 답변이 가능합니다. 상단 배너에서 모드를 확인하세요.

Q. 하단 탭이 너무 많아 글자가 잘립니다

모바일에서 탭이 6개입니다. 화면이 좁으면 아이콘 아래 글자가 줄임표로 표시될 수 있습니다. 태블릿(640px 이상) 또는 PC에서 접속하면 모든 탭명이 정상 표시됩니다.
